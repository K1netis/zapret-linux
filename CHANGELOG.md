# История изменений

## 1.2.0

- `sudo zapret test` теперь проверяет **все стратегии сразу** и выдаёт рейтинг
  от лучшей к худшей. Раньше подходящую стратегию приходилось искать по одной:
  применить, проверить, следующую — при двадцати с лишним стратегиях это долго.
  Теперь каждая стратегия запускается в отдельном экземпляре движка, и все
  проверяются одновременно; рабочая служба при этом не останавливается.
- Порядок в рейтинге: сначала сколько проверок прошло, затем скорость установки
  соединения, затем простота стратегии (меньше лишних пакетов-фейков).
- Проверка стала честнее. Раньше тест скачивал страницу целиком одним запросом
  и при неудаче писал только «нет ответа» — так рабочая стратегия могла выглядеть
  нерабочей. Теперь каждый адрес проверяется несколькими способами (TLS 1.2,
  TLS 1.3, HTTP/1.1, загрузка 64 КБ), случайные единичные сбои перепроверяются,
  а у каждой неудачи указана причина: таймаут, обрыв на N КБ, сброс, ошибка
  сертификата, DNS.
- Тест показывает, какие адреса открываются и без zapret, и сохраняет полный
  отчёт в `/etc/zapret-linux/test-report.txt`.
- `sudo zapret test <имя> ...` проверяет только указанные стратегии.
- Список проверяемых адресов — тот же, что в тестах Flowseal, — лежит в
  `/opt/zapret-linux/targets.txt`, в него можно добавить свои.

## 1.1.5

Исправления. После обновления выполните `sudo zapret sync`: синхронизация
скачает полный список IP и заново переведёт стратегии.

- Исправлено: режим `zapret ipset none` на деле пропускал под профили с
  ipset **весь** трафик. Движок считает пустой список отсутствующим, а `none`
  записывал именно пустой. Теперь `none`, как у Flowseal, — адрес-заглушка.
- Исправлено: режим `loaded` на деле работал как `none`. У Flowseal файл
  `ipset-all.txt` содержит только заглушку, а полный список лежит в
  `ipset-all.txt.backup`, который `zapret sync` не скачивал. Теперь скачивает,
  и `loaded` загружает полный список (около 33 тысяч подсетей).
- Режим IPSet по умолчанию — `none`, как в репозитории Flowseal. Если у вас
  стоял `loaded`, при обновлении он станет `none`: прежний `loaded` и так
  работал как `none`, поэтому фактически ничего не изменится. Включить полный
  список: `sudo zapret ipset loaded`.
- Исправлено: стратегия `general (FAKE TLS AUTO)` не запускалась — служба
  уходила в цикл перезапусков. Символ `^` в стратегиях Flowseal — экранирование
  командной строки Windows, а переносился он как часть параметра. Уже
  переведённые стратегии исправляются при применении.
- Файлы `*-user.txt` больше не создаются пустыми: в них пишется заглушка, как
  у Flowseal. Пустые файлы от прежних версий заполняются ею же.
- Проверка перед перезапуском службы находит отсутствующий файл в любом
  параметре стратегии, а не только в списках и фейках.
- `zapret update`:
  - если не хватает списков или фейков, честно сообщает, что файлы обновлены,
    а стратегия не применена, и советует `sudo zapret sync`. Раньше он писал,
    что версия не обновилась, и повтор отвечал «у вас актуальная версия»;
  - сверяет версию в скачанном архиве: пока GitHub отдаёт старый архив из
    кэша, предлагает повторить через 5 минут, а не ставит старую версию под
    новым номером;
  - работает с форками под любым именем.
- Установщик больше не может выбрать готовый nfqws чужой архитектуры.

## 1.1.4

Безопасность. Рекомендуется обновиться всем.

- Закрыта уязвимость: текст стратегии Flowseal мог выполниться на вашей машине
  как команда с правами root. Если бы в репозиторий Flowseal (или в форк,
  указанный вместо него) попала стратегия с подстановкой команды — в параметрах
  или даже в имени файла, — она сработала бы при `zapret sync`, `zapret use`,
  `zapret game`, `zapret ipset` или при запуске службы. Теперь:
  - транслятор принимает только символы, из которых состоят настоящие
    параметры nfqws, и отказывается переводить всё остальное (прежняя рабочая
    версия стратегии при этом сохраняется);
  - файлы стратегий больше не выполняются как скрипты, а разбираются;
  - каждый параметр в команде запуска службы заключён в кавычки, так что
    оболочка ничего в нём не раскрывает.
- `zapret sync` пропускает файлы с подозрительными именами (например, с
  `../`), а не записывает их куда попало.
- `zapret fakes set` принимает только имя файла из `bin/`, без пути: раньше
  можно было указать любой файл системы, и он ушёл бы в сеть как фейк.
- `zapret use` принимает только имя стратегии, без пути.
- Значения в `/etc/zapret-linux` (порты и режим игрового фильтра, подмены
  фейков) проверяются перед применением: испорченная вручную настройка
  заменяется значением по умолчанию с предупреждением, а не попадает в команды.
- `active.env` и команда запуска службы записываются целиком за один шаг:
  сбой не оставит их наполовину записанными.
- `uninstall.sh` отказывается удалять каталоги, которые не похожи на каталоги
  zapret-linux.
- Сообщения, которые оставались на английском, переведены.

## 1.1.3

- Исправлено: в конце `zapret update` могли появляться ошибки вида
  «команда не найдена» и «неожиданный конец файла». bash читает скрипт по ходу
  выполнения, а установщик перезаписывал `update.sh`, пока тот работал, — после
  установки bash продолжал читать из середины нового файла. Само обновление при
  этом завершалось успешно, но исполнение обрывков кода опасно в принципе.
  Теперь установщик заменяет все файлы через новую копию и переименование, а
  `update.sh` дополнительно работает из временной копии самого себя.
- Установщик не перезаписывает файлы, которые не изменились.

## 1.1.2

- Исправлено: `zapret update` падал с ошибкой «Текстовый файл занят», потому что
  установщик пытался перезаписать бинарник nfqws, пока он работает в службе.
  Теперь новая копия кладётся рядом и переименовывается — служба дорабатывает
  со старой, после перезапуска использует новую. Если бинарник не изменился,
  он не копируется вовсе.
- Исправлено: при сбое установка могла остаться наполовину выполненной, но уже
  с новым номером версии — тогда `zapret update` считал обновление завершённым
  и не повторял попытку. Теперь nfqws ставится первым, а номер версии
  записывается последним, когда все файлы на месте.
- Установщик больше не копирует в `bin/` фейки из движка bol-van: стратегиям
  Flowseal они не нужны, а `zapret sync` удалял их как неиспользуемые, и при
  каждой переустановке они появлялись снова.
- Сообщение об ошибке обновления теперь соответствует действительности.

## 1.1.1

Надёжность синхронизации со стратегиями Flowseal.

- `zapret sync` удаляет стратегии, списки и фейки, которых больше нет у Flowseal.
  Не удаляется то, что ещё используется: активная стратегия (вместо удаления —
  предупреждение с советом переключиться), файлы, на которые ссылаются
  оставшиеся стратегии или подмена фейков, ваши `*-user.txt` и собственные
  стратегии, созданные не транслятором.
- `zapret sync` больше не может испортить рабочую установку при сбое.
  Всё скачивается и переводится во временную папку, рабочие файлы подменяются
  только после успешной загрузки всего набора. Раньше обрыв сети мог заменить
  рабочий файл недокачанным, а недоступность GitHub API (например, исчерпанный
  лимит запросов) приводила к молчаливому «готово» без единой стратегии.
- Если Flowseal вводит в стратегию что-то новое, что транслятор ещё не умеет
  переводить, прежняя рабочая версия этой стратегии сохраняется, а остальные
  обновляются. Раньше рабочий файл обнулялся, а синхронизация обрывалась.
- Вывод `zapret sync` показывает только изменения (`+` добавлено, `~` обновлено,
  `-` удалено) и итоговую сводку, а не перечень всех файлов. Убрана подсказка
  про `git diff`, адресованная разработчику.
- Повторный запуск `install.sh` поверх рабочей установки больше не сбрасывает
  выбранную стратегию на `general`.
- При обновлении и переустановке вместо полной справки выводится короткое
  сообщение с номерами версий.
- Сообщения транслятора переведены на русский.

## 1.1.0

Синхронизация с Flowseal 1.10.3.

- Порты игрового фильтра теперь настраиваются, как в Flowseal 1.10.3:
  `zapret game ports tcp 1024-1934,1936-65535`. Например, так можно исключить
  RTMP (порт 1935) из обработки. Сброс на значения по умолчанию —
  `zapret game ports reset`.
- Исправлено: при выключенном игровом фильтре его профили всё равно получали
  диапазон 1024-65535, из-за чего часть трафика на порты 2053-8443 и
  50000-50100 обрабатывалась игровыми профилями. Теперь, как и в Windows-версии,
  подставляется порт-заглушка, и выключенный фильтр ничего не перехватывает.
- `zapret game` передаёт все аргументы, а не только первый.
- `zapret status` показывает порты игрового фильтра.
- Сообщения `gamefilter.sh` переведены на русский.

Новая стратегия ALT13 и обновлённые списки Flowseal приходят через
`zapret sync`, изменений кода для них не требуется.
