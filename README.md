# zapret-linux

Обход блокировок DPI на Linux: движок [zapret](https://github.com/bol-van/zapret)
от bol-van плюс готовые стратегии из
[zapret-discord-youtube](https://github.com/Flowseal/zapret-discord-youtube)
от Flowseal, собранные в systemd-службу с одной понятной командой управления.

```
sudo zapret test                # проверить все стратегии сразу
sudo zapret use general_alt11   # применить лучшую
```

## Зачем это нужно

Оригинальный zapret — мощный, но недружелюбный инструмент. Он даёт движок и
десятки параметров вида `--dpi-desync=fake,multisplit --dpi-desync-split-seqovl=681`,
но не даёт ответа на главный вопрос новичка: *какие именно параметры вписать,
чтобы заработал YouTube*. Подбор рабочей комбинации — отдельная задача, которая
у большинства людей заканчивается на этапе чтения документации.

У Flowseal эта задача решена: там лежат десятки готовых, протестированных
конфигураций, а сообщество правит их в реальном времени, когда провайдеры меняют
методы блокировки. Проблема одна — всё это работает только под Windows, потому
что использует `winws.exe` и драйвер WinDivert.

При этом Windows-версия и Linux-версия zapret собираются **из одного исходного
кода**. Различаются они по сути только способом перехвата пакетов: WinDivert на
Windows против NFQUEUE на Linux. Язык параметров обхода — одинаковый.

Отсюда идея проекта: не изобретать свои стратегии (это долго, а результат
устаревает), а взять готовые от Flowseal, автоматически перевести их в форму,
понятную Linux-версии движка, и завернуть в нормальную службу с человеческим
управлением.

## Как это устроено

Перевод стратегии из Windows в Linux сводится к нескольким механическим заменам:

| Windows (`winws.exe`)                   | Linux (`nfqws`)                                    |
|-----------------------------------------|----------------------------------------------------|
| `--wf-tcp=` / `--wf-udp=` (список портов)| правила nftables, направляющие эти порты в NFQUEUE |
| `%BIN%файл` / `%LISTS%файл`             | абсолютные пути в `/opt/zapret-linux`              |
| `%GameFilterTCP%` / `%GameFilterUDP%`   | подставляются из состояния переключателя           |
| *(аналога нет)*                          | `--qnum=200` и `--dpi-desync-fwmark` — только для Linux |
| `--filter-*`, `--dpi-desync-*`, `--hostlist*`, `--ipset*`, `--new` | переносятся без изменений |

Строка с пометкой «аналога нет» — единственное, что добавляется, а не переносится. `--qnum`
задаёт номер очереди NFQUEUE, которых в Windows просто нет. А `--dpi-desync-fwmark`
нужен, потому что поддельные пакеты, отправленные nfqws, снова проходят через
правила firewall: без метки они попадали бы в очередь повторно и зациклились.
nfqws помечает свои пакеты, а правило nftables такие пакеты пропускает мимо.

Этим занимается `tools/bat2nfqws.sh`. Он же прекращает работу с ошибкой, если
встречает незнакомую конструкцию, — лучше явный отказ, чем молча собранная
нерабочая команда.

```
tools/bat2nfqws.sh     перевод стратегий Flowseal (.bat) в формат nfqws
sync-flowseal.sh       загрузка стратегий, списков и фейков из репозитория Flowseal
strategies/*.conf      переведённые стратегии
lib/fw.sh              создание и снятие правил nftables
apply-strategy.sh      сборка команды запуска и перезапуск службы
gamefilter.sh          игровой фильтр: off | tcp | udp | all
ipsetfilter.sh         режим IPSet: none | loaded | any
fakes.sh               подмена .bin-фейков
status.sh, selftest.sh диагностика; targets.txt — адреса для zapret test
update.sh              обновление самого zapret-linux
zapret-cli             единая команда управления
```

## Требования

- Linux с systemd (проверено на Arch, Ubuntu, Debian)
- `nftables`, `git`, `curl`
- для сборки движка: `gcc`, `make`, `zlib`, `libnetfilter_queue`, `libnfnetlink`, `libmnl`

Debian / Ubuntu:

```sh
sudo apt install nftables git curl gcc make zlib1g-dev \
                 libnetfilter-queue-dev libnfnetlink-dev libmnl-dev
```

Arch:

```sh
sudo pacman -S nftables git curl base-devel libnetfilter_queue libnfnetlink libmnl
```

## Установка

```sh
git clone https://github.com/K1netis/zapret-linux
cd zapret-linux
sudo bash install.sh
```

Установщик сам загрузит движок, соберёт `nfqws`, скачает актуальные стратегии и
списки от Flowseal, установит службу и применит стратегию по умолчанию.

Каталог с исходниками после установки можно удалить: всё необходимое, включая
обновление и удаление, копируется в `/opt/zapret-linux`.

Если проект скачан архивом, а не через `git clone`, файлы могут потерять признак
исполняемости, и тогда `sudo ./install.sh` выдаст «команда не найдена». Запускайте
`sudo bash install.sh` — он восстановит права самостоятельно.

## Использование

Всё управление — через команду `zapret`.

| Команда | Что делает |
|---|---|
| `zapret` | коротко: работает ли служба, какая стратегия активна |
| `sudo zapret status` | подробности: счётчики пакетов по портам, журнал службы |
| `sudo zapret test` | проверить все стратегии сразу и показать рейтинг; `sudo zapret test <имя> ...` — только указанные |
| `zapret list` | список доступных стратегий |
| `sudo zapret use <имя>` | переключиться на другую стратегию |
| `sudo zapret game udp` | игровой фильтр: `off`, `tcp`, `udp`, `all` |
| `sudo zapret game ports` | порты игрового фильтра |
| `sudo zapret ipset loaded` | режим IPSet: `none`, `loaded`, `any` |
| `sudo zapret fakes list` | подмена фейков, используемых стратегией |
| `sudo zapret sync` | обновить стратегии от Flowseal |
| `sudo zapret update` | обновить сам zapret-linux |
| `sudo zapret log 50` | последние строки журнала |
| `sudo zapret start` / `stop` / `restart` | управление службой |
| `sudo zapret enable` / `disable` | автозапуск при загрузке |
| `sudo zapret uninstall` | полное удаление |

### Подбор рабочей стратегии

Универсальной стратегии не существует: провайдеры блокируют по-разному, и то,
что работает у одного, не работает у другого. Стратегии также перестают работать
со временем, когда провайдер меняет оборудование или настройки.

Поэтому подбор — это нормальная часть работы, и делает его одна команда:

```sh
sudo zapret test               # все стратегии сразу, обычно 1–3 минуты
sudo zapret use general_alt2   # применить ту, что оказалась лучшей
```

`zapret test` запускает все стратегии одновременно — каждую в отдельном
экземпляре движка — и проверяет с каждой одни и те же адреса (Discord, YouTube,
Google, Cloudflare; список в `/opt/zapret-linux/targets.txt`) несколькими
способами: TLS 1.2, TLS 1.3, HTTP/1.1 и загрузку первых 64 КБ, на которой видно
характерный обрыв соединения на 16–20 КБ. Работающая служба при этом не
останавливается: проверочный трафик идёт мимо неё.

Результат — таблица от лучшей стратегии к худшей:

- **пройдено** — сколько проверок прошло; это главное;
- **время** — медиана установки защищённого соединения. Стратегии, которые
  укладываются в 50 мс от самой быстрой, считаются одинаково быстрыми;
- **слож.** — сколько лишних пакетов-фейков стратегия отправляет на соединение.
  Фейки нужны только в начале соединения, поэтому на скорость скачивания они
  почти не влияют, но при прочих равных выше стоит более простая стратегия;
- **главные проблемы** — какие адреса не открылись и почему: таймаут, обрыв на
  N КБ, сброс, ошибка сертификата (часто признак подмены DNS провайдером).

Отдельно показывается, что открывается и без zapret: такие адреса мало говорят о
стратегиях. Полный отчёт сохраняется в `/etc/zapret-linux/test-report.txt`.

Тест проверяет TCP. Браузер открывает YouTube по QUIC (UDP), а проверить QUIC
можно, только если ваш curl собран с поддержкой HTTP/3 — тест сообщит об этом.
Окончательная проверка — открыть нужные сайты и приложения самому.

### Игровой фильтр

Профили Flowseal покрывают известные порты Discord, YouTube и подобных сервисов.
Игры и голосовая связь часто используют порты в широком диапазоне, который в
обычный список не входит. Игровой фильтр добавляет в обработку диапазон
1024-65535:

```sh
sudo zapret game udp    # только UDP — обычно этого достаточно для голоса и игр
sudo zapret game all    # TCP и UDP
sudo zapret game off    # выключить
```

Начинайте с `udp`: режим `all` захватывает заметно больше трафика и может
замедлить работу.

Диапазон портов можно изменить. Например, чтобы не трогать стриминг по RTMP
(порт 1935):

```sh
sudo zapret game ports tcp 1024-1934,1936-65535
sudo zapret game ports udp 1024-65535
sudo zapret game ports           # показать текущие
sudo zapret game ports reset     # вернуть 1024-65535
```

Порты задаются числами и диапазонами через запятую, без пробелов.

### Режим IPSet

Управляет тем, какие адреса попадают под профили, привязанные к списку IP:

- `none` — ни одного адреса (по умолчанию, как в репозитории Flowseal);
- `loaded` — полный список адресов Flowseal (`lists/ipset-all.txt.backup`,
  его загружает `zapret sync`);
- `any` — любые адреса. Затрагивает весь трафик, годится только для диагностики.

## Обновления

В проекте два независимых механизма обновления.

```sh
sudo zapret sync      # стратегии, списки и фейки от Flowseal
sudo zapret update    # сам zapret-linux
```

`zapret sync` нужен, когда сообщество Flowseal выпустило новые или исправленные
стратегии — именно это чаще всего чинит внезапно переставший работать сервис.
Скрипт перечисляет содержимое репозитория Flowseal через GitHub API, поэтому
новые стратегии подхватываются автоматически, без правок кода. Удалённое у
Flowseal убирается и у вас — кроме того, что ещё используется, например
активной стратегии.

Синхронизация безопасна: всё скачивается во временную папку, и рабочие файлы
меняются, только если загрузка прошла целиком. При ошибке сети или GitHub
установка остаётся как была. В выводе видны только изменения:

```
  + strategies/general_alt13.conf     добавлено
  ~ lists/list-general.txt            обновлено
  - bin/quic_initial_dbankcloud_ru.bin  удалено
```

`zapret update` обновляет сам проект: скрипты, службу, транслятор. Что
изменилось в каждой версии — в [CHANGELOG.md](CHANGELOG.md). Текущая
стратегия, режимы фильтров и ваши списки сохраняются, уже собранный движок
используется повторно, так что переустановка не требуется.

Если вы делаете свой форк, укажите его в `repo.conf`:

```
UPDATE_REPO=K1netis/zapret-linux
UPDATE_BRANCH=main
```

## Свои списки

Файлы с суффиксом `-user` предназначены для ваших правок и не перезаписываются
при обновлении:

- `lists/list-general-user.txt` — домены, которые нужно обрабатывать;
- `lists/list-exclude-user.txt` — домены, которые нужно пропускать мимо;
- `lists/ipset-exclude-user.txt` — адреса, которые нужно пропускать мимо.

Как и у Flowseal, пустыми эти файлы не бывают: в них лежит строка-заглушка
(`domain.example.abc` или `203.0.113.113/32`). Пустой список движок считает
отсутствующим, поэтому заглушку можно не удалять — свои строки добавляйте рядом.

После правки примените изменения: `sudo zapret restart`.

## Если что-то не работает

**Служба не запускается.** Смотрите `sudo zapret log 50`. Чаще всего не хватает
файлов — решается командой `sudo zapret sync`.

**Счётчики в `zapret status` нулевые.** Трафик не доходит до обработки. Проверьте,
не мешает ли другой firewall, и помните, что правила ловят только начало новых
соединений — уже открытые вкладки не считаются.

**YouTube работает, а Discord нет.** Две частые причины. Первая: выключен игровой
фильтр, а голосовая связь использует порты выше покрытых профилем —
`sudo zapret game udp`. Вторая: системный DNS. Браузер обычно ходит через
DNS-over-HTTPS, а настольное приложение Discord использует системный резолвер,
и без защищённого DNS часть адресов не разрешается. Настройте DNS-over-TLS или
DNS-over-HTTPS на уровне системы.

**Ничего не помогает.** Запустите `sudo zapret test` и посмотрите на столбец
«главные проблемы» и раздел «без обхода». Если не работает ни одна стратегия, проверьте
свежие обсуждения в репозитории Flowseal — вероятно, провайдер изменил блокировку
и рабочая стратегия ещё не готова.

## Удаление

```sh
sudo zapret uninstall                 # с подтверждением
sudo zapret uninstall --keep-lists    # сохранить свои списки
```

Удаляются служба, правила nftables, `/opt/zapret-linux`, `/etc/zapret-linux` и
команда `zapret`.
